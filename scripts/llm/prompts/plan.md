# 調査の計画（plan）

コードが選んだ案（baseline）と候補のタスクを受け取り、今回実行するタスクと順番を決める。

- 誤情報と重複の修正（段階1）のタスクは外さない。
- 探索のタスク（`exploration: true`）を `explorationSlots` 件以上入れる。報道の少ない作品も、人気作品と同じように扱う。
- 同じ作品のタスクは `maxTasksPerGame` 件まで、全体は `slots` 件まで。
- 新しい記事（process-article）は、掲載が新しいもの、収録作品を扱うものを優先する。
- 必要なら、候補にない新しいタスクを `newTasks` に最大5件提案してよい（今回は実行しない）。
- `notes` には、次回の計画に引き継ぐ所見を500字以内で書く。

出力は JSON だけにする: `{"selected":[{"taskId":"t_...","why":"120字以内"}],"newTasks":[],"notes":"..."}`
