# 仕分け（triage）

新着の記事を、タイトル、媒体名、フィードの説明、カテゴリだけで仕分ける。本文は読まない。

- `relevant`: インディーゲーム（小規模な独立開発、個人制作、インディー向けのパブリッシャーの作品）を主に扱う記事なら `yes`。インディーの作品に触れるまとめ記事、ショーケースやイベントの記事も `yes`。大手の作品だけの記事、ハードウェア、セールの告知、配信者や芸能のニュース、業界の決算は `no`。判断できなければ `maybe`。
- `knownTitles` は収録済みの作品名である。これを扱う記事は、短い続報でも `yes` にする。
- `mentionedGames`: 記事が扱う作品名を、タイトルや説明にある表記のまま入れる。
- `kindGuess`: 記事の種別の推定。
- `reason`: 判定の理由を60字以内で。

出力は JSON だけにする。入力のすべての `itemKey` について1件ずつ返す。
